## 同一地区为什么有两个价：家宽版贵的是 IP 属性

英国有两个套餐，¥70.09 的原生家宽和 ¥41.86 的 TikTok 专线，配置几乎一样，都是 1 核 512MB 内存 10GB 硬盘 200Mbps。新加坡同样如此，家宽直播版 ¥117.13，原生版 ¥79.49，差 37.64 元。

多出来的钱买的是 IP 在平台风控眼里的身份。机房 IP 和住宅 IP 在 TikTok 的识别体系里不是一个信任等级，原生住宅 IP 意味着这个地址在 IP 数据库里被标注为家庭宽带，平台看到的是“一个本地用户在正常上网”，而不是“一批账号从一个机房同时登录”。做矩阵号、养号的人对这点最敏感，一个不干净的 IP 能让前面几个月的运营白做。

所以选型规则很短：起号、养号、矩阵运营，优先买家宽版；只是给已有账号发视频、测试内容方向，¥41.86 的原生专线够用，性价比高得多。

## 哪些机房必须中转，哪些能直连

必须中转的只有西班牙一个，测评里写的是“必须中转才能使用”。英国原生家宽、法国、加拿大、南非标的是“建议中转”，这三条不是不能用，是直连体验不稳。台湾节点三网都绕，直播必须中转。印尼、越南、马来西亚、泰国、德国标注的是“电信用户需中转”，移动和联通用户受影响小一些。

标三网直连的只有四条：日本、韩国、洛杉矶 9929、洛杉矶 GTT/NTT。这四条是给不想折腾中转的人准备的，价格也就相应高一些。

两个细节值得提前知道。第一，流量是双向计算的，标 1TB 就是上传加下载一共 1TB，不是单向。第二，部分套餐达量后限速到 5Mbps 或 10Mbps，不停机也不额外收费，跑直播的话限速之后基本只能维持在线、没法推高清流。

洛杉矶新上的 GTT/NTT 那款用的是 192 网段全新 IP，上游 NTT（AS2914），回程三网强制走联通 AS9929，200Mbps 带宽 1.5TB 双向流量。测评的说法是联通用户体验最流畅，电信和移动也属优秀。韩国仁川节点有测评确认走 AS45996（DAOU TECHNOLOGY），定位是原生家宽 IP，适合韩流内容和直播场景，但公开的测速数据不多。

## 南非节点：22.41 澳元买的是什么

南非是 2026 年 6 月上的，1 核 Xeon Gold 6138（2.00GHz）、512MB DDR4、10GB SSD、100Mbps 带宽、2TB 双向月流量、1 个南非原生住宅 IPv4。原价 AUD 24.90，用 WePCMON90 月付打 9 折是 22.41 澳元，季付 65.43，年付 239.04。

它的价值在稀缺性。非洲机房本来就少，能把南非住宅 IP 做成标准套餐的商家屈指可数，做南非 TikTok 切片、南非 Netflix 解锁、本地化广告测试，这类需求基本没有别的选择。

问题在延迟。南非到国内 Ping 大约 397ms，物理距离决定的，绕不开。路由上电信去程经美国和英国，联通走德国和英国，移动全程经英国，丢包控制得不错。硬件实测内存可用 487MB，SSD 平均读写 163MB/s，KVM 虚拟化可以自己装 BBR，国内外下载都能跑到 90Mbps 以上，国内上传 60Mbps 以上，撑 2 到 3 台设备做切片没问题。

拿它直接直播会卡。写南非那篇测评的作者自己也不建议这么干，合理方案是配一台欧洲优化线路的 VPS 或者南非 CN2 GIA 做中转，把南非机当落地机用，这样既有住宅 IP 属性，又把实际延迟压下来。

另外提一句，南非这个节点算不算严格意义的双 ISP 家宽，第三方说法不一致：专门写南非的测评说检测工具确认为双 ISP 原生家庭宽带，另一份价格整理里标的是“原生 IP（非家宽）”。如果你的业务对 IP 类型卡得很死，下单前发工单问清楚。

## 常见问题

**支持哪些支付方式？**
支付宝、信用卡、PayPal，另有资料提到微信。用 PayPal 的话要在注册时把币种选成澳币，否则可能吃一层汇率损失。结算货币是澳元，人民币支付按实时汇率转换。

**流量用超了会停机吗？**
不会。部分套餐达量后限速到 5Mbps 或 10Mbps，不额外收费。但限速状态下推流质量会明显下降，长期跑直播的建议直接选流量大的套餐。

**买了不会配置怎么办？**
车库云有个收费的“TK”服务，技术团队帮你把 TikTok 需要的环境配好，拿到手直接用。自己会折腾的可以跳过，这笔钱省下来买中转更划算。

**南非能直接直播吗？**
不建议。397ms 的延迟对推流来说太高，会出现明显卡顿和互动延迟，当落地机配中转才是正常用法。

**续费会涨价吗？**
用 WePCMON90 和 WePCYEAR80 下单的，官方口径是循环优惠，续费同价。没填码按原价买的，续费也还是原价。
